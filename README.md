# 09 提示词工程

> 对应规划：阶段四（V1.0）/ 阶段五（V2.0）/ 阶段六（V3.0 最终版）

## 一、功能
集中管理盲道场景的视觉大模型提示词，三个迭代版本：
- **V1.0**（阶段四）：基础 JSON 输出约束，建立识别字段雏形。
- **V2.0**（阶段五）：补充业务语义——盲道偏移方向含义、障碍三级风险定义，与 06 业务逻辑对齐。
- **V3.0**（阶段六，**最终版**）：针对逆光/暗光/磨损/遮挡/雨天等 200+ 真实样本迭代，强化鲁棒性与推理步骤，输出字段与 `protocol.h` 严格一致。

## 二、作用
- 决定云端识别质量的“灵魂”。同样的大模型，提示词优劣直接决定准确率是否达标（盲道≥85%、障碍≥80%）。
- 被 `08_云端识别服务/llm_client.py` 以 `from prompts import PROMPT_V3` 引用，是云端的输入契约。

## 三、拼接方法
1. 部署时把 `prompts.py` 复制到 `08_云端识别服务/` 同级目录（或加入 `PYTHONPATH`）。
2. 如需回退测试不同版本，改 `llm_client.py` 的 `from prompts import PROMPT_V3` 为 `PROMPT_V1` / `PROMPT_V2` 即可对比准确率。
3. 提示词字段（`blind_path`/`obstacles`/`feedback` 及子字段）必须与 `01_数据协议与引脚配置/protocol.h` 的 `K_*` 宏一一对应；端侧解析依赖这些键名，改动需两端同步。
4. 实测发现高误报场景后，在此迭代 V3→V3.x，并同步更新 06_核心业务逻辑模块 的阈值与 10_测试与验证 的测试集。
