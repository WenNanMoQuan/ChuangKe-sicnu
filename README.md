# 10 测试与验证模块

> 对应规划：阶段七（系统验证与交付定型）

## 一、功能
提供两类测试资产：
1. **接口联调客户端** `test_client.py`：向 `08_云端识别服务` 发送一张测试图（协议一致 JSON），打印识别结果，替代 Postman 做端云联通验证。
2. **状态机单元测试** `test_fsm.py` + `fsm_model.py`：用 pytest 验证 06 模块的“三帧滑动窗口防抖”逻辑（含偶发误识别过滤、连续两帧切换、终止态转换等用例）。
3. **测试计划** `test_plan.md`：覆盖功能/性能/稳定性/实地四类测试与验收口径。

## 二、作用
- 把阶段七“全维度测试验证、闭环问题、冻结版本”落到可执行步骤。
- `fsm_model.py` 是 06 算法的 Python 参考实现，保证无硬件也能验证核心逻辑正确性。

## 三、拼接方法
1. 云端联调：先启动 08 服务，再运行
   ```bash
   python test_client.py 测试图.jpg http://<服务器IP>:5000
   ```
   检查返回 JSON 字段与 `protocol.h` 一致。
2. 状态机单测：在本目录执行
   ```bash
   pip install pytest && pytest test_fsm.py -v
   ```
3. 算法一致性：若修改 06 的防抖窗口（3 帧）或阈值，需同步更新 `fsm_model.py` 并补用例。
4. 现场实测按 `test_plan.md` 执行，结果归档到 TF 卡日志（由 07 主固件写入）并导出分析。
